🪟 Windows Tips

  • Win + R → %temp% → remove temporary files you no longer need.
  • Win + R → temp → clean temporary files where Windows allows it.
  • Keep Windows and device drivers updated.
  • Disable unnecessary startup apps in Task Manager.
  • Keep reasonable free storage on the system drive.
  • Use Storage Sense to automate temporary-file cleanup.
  • Uninstall software you no longer use.
  • Use a lightweight browser tab/session setup when RAM is limited.
  • Check Task Manager for CPU/RAM/Disk bottlenecks before blaming hardware.
  • Scan for malware if unexplained lag suddenly appears.
Tip: never force-delete files that Windows says are in use. Clean only what the system allows.

📱 Android Tips

  • Use CapCut Mobile for mobile editing.
  • Use ChatGPT for thumbnail concepts and editing guidance.
  • When you hit a ChatGPT limit, Gemini can be another option for image generation.
  • Use Canva for deeper, creative thumbnail design.
  • Keep enough free storage for smoother editing.
  • Close heavy background apps before rendering.

🖥️ PC Building & Laptops

  • Sharpy Server can publish builds under ₹20K, ₹50K, ₹80K, ₹1L, ₹1.5L and ₹2L.
  • Compare CPU + GPU balance instead of judging one part alone.
  • Prioritize a reliable PSU.
  • Check upgrade paths before choosing a motherboard.
  • For laptops, compare thermals, display, RAM upgradeability, battery and GPU/CPU together.
